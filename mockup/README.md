# UI Mockup: Login, SingUp & กรอกที่อยู่

โปรเจกต์ Mockup หน้าจอการทำงานโมบายล์ 3 ขั้นตอน ตามลำดับภาพต้นฉบับ:
1. **Login** (เข้าสู่ระบบ)
2. **SingUp** (ลงทะเบียนผู้ใช้ใหม่)
3. **กรอกที่อยู่** (ยืนยันข้อมูลและที่อยู่จัดส่ง)

---

## 📱 วิธีเปิดใช้งาน

### วิธีที่ 1: เปิดไฟล์ตรงผ่าน Browser (ไม่ต้องลงโปรแกรมเพิ่ม)
- ดับเบิลคลิกที่ไฟล์ [`index.html`](file:///index.html) ในโฟลเดอร์นี้เพื่อเปิดใช้งานได้ทันทีใน Chrome, Edge, Safari หรือ Firefox

### วิธีที่ 2: รัน Local Server (Node.js)
```bash
node server.js
```
จากนั้นเปิด Browser ไปที่: [http://localhost:3000](http://localhost:3000)

---

## ✨ ฟีเจอร์พิเศษที่สร้างให้

1. **โหมดดู 3 หน้าพร้อมกัน (Overview 3 Screens)**:
   - แสดงทั้ง 3 จอ (Login, SingUp, กรอกที่อยู่) วางเรียงข้างกันแบบ Artboard เหมือนในรูปภาพตัวอย่าง
   - สามารถพิมพ์ กรอกข้อมูล หรือกดปุ่มได้ทุกหน้าจอพร้อมกัน

2. **โหมดทดลองใช้งานจริง (Interactive Flow)**:
   - กดปุ่ม **"ทดลองใช้งานจริง (Interactive Flow)"** ที่แถบเมนูด้านบน
   - หน้าจอจะปรับเป็นโทรศัพท์เครื่องเดียว พร้อม Stepper บอกสถานะขั้นตอน 1 -> 2 -> 3
   - สามารถคลิก "SINGUP" จากหน้า Login เพื่อสลับไปหน้า SingUp
   - เมื่อกดปุ่มจาก SingUp จะนำทางไปยังหน้า "กรอกที่อยู่" อัตโนมัติ

3. **ปุ่ม "กรอกข้อมูลตัวอย่าง" (Autofill Demo)**:
   - มีปุ่มทางลัดด้านบน กดเพียง 1 คลิกเพื่อเติมข้อมูลภาษาไทยและเลขบัตรตัวอย่างลงในทุกช่อง สะดวกต่อการพรีเซนต์หรือทดสอบ UI

4. **ระบบ Format เลขบัตรประชาชนและเบอร์โทรศัพท์**:
   - เลขบัตรประชาชนจัดรูปแบบอัตโนมัติ: `x-xxxx-xxxxx-xx-x`
   - เบอร์โทรศัพท์จัดรูปแบบอัตโนมัติ: `0xx-xxx-xxxx`

5. **ปุ่มเปิด/ปิดดูรหัสผ่าน (Show/Hide Password)**:
   - มีไอคอนรูปดวงตาสำหรับกดแสดง/ซ่อนรหัสผ่านในช่อง Password

6. **หน้าต่างยืนยันผลลัพธ์ (Summary & Success Modal)**:
   - เมื่อกรอกข้อมูลในหน้า "กรอกที่อยู่" และกดปุ่ม **"ยืนยัน"** จะมีป๊อปอัปสรุปข้อมูลและแจ้งเตือนบันทึกข้อมูลสำเร็จ

## 🎨 ไฟล์ในโปรเจกต์

- [`index.html`](file:///index.html): โครงสร้างหน้าจอทั้ง 3 จอ พร้อม SVG ไอคอน Google, Facebook, Apple
- [`style.css`](file:///style.css): ตกแต่งสไตล์ โทนสี Palette ปุ่มสีเขียวมินต์ (`#6ce5b9`), แบ็กกราวด์โทรศัพท์สีฟ้าอ่อน (`#f2f7fb`), และฟอนต์ Kanit / Inter
- [`app.js`](file:///app.js): ระบบการสลับโหมด, ตรวจสอบความถูกต้อง, จัดฟอร์แมตตัวเลข และแจ้งเตือน
- [`server.js`](file:///server.js): เว็บเซิร์ฟเวอร์แบบเบาพิเศษด้วย Node.js
