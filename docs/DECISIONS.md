# Decisions and assumptions — 23 ตุลาคม 2026

- ไม่มี repo เดิมใน workspace หรือพาธ `D:\test code\HarnKhong` และ Build Kit ไม่มีโค้ด จึงสร้างโปรเจกต์ใหม่ในโฟลเดอร์ส่งมอบ โดยอิง flow ของ Prototype HTML ที่อ่านได้ในแชต ChatGPT โปรเจกต์ “หารของ” ไม่กล่าวอ้างว่าเป็นการแก้ source เดิม
- ใช้ Vite + JavaScript modules และ CSS ปกติ เพื่อลด dependency; ไม่มี backend ในชุดไฟล์
- ราคา authoritative ใช้ integer satang; การป้อนบาทรับทศนิยมสูงสุด 2 ตำแหน่ง; เศษสตางค์ให้สมาชิกตามลำดับเข้ากลุ่ม
- ให้สร้างกลุ่มขั้นต่ำ 2 สูงสุด 20 คน; หัวหน้ากลุ่มต้องโอนสิทธิ์ก่อนออก
- ทุกการเปลี่ยนสมาชิกหรือต้นทุนเพิ่ม revision และล้าง approvals; order demo ต้องสมาชิกเต็มและ approvals ปัจจุบันครบ
- ราคาต่อคนบน card เป็น **ประมาณเมื่อสมาชิกครบ** เพื่อไม่สื่อว่าเป็นยอดที่ตกลงแล้ว; หน้า group แสดงยอดปัจจุบันของแต่ละคนและ revision
- ค่าบริการเริ่มต้น 0 และแสดงสินค้า ค่าส่ง ค่าบริการแยกกัน
- เริ่มจากสินค้าทางกายภาพและงานพิมพ์ที่มีเงื่อนไขตรวจสอบได้ หลีกเลี่ยงการแชร์สมาชิกบริการดิจิทัลซึ่งอาจขัดข้อกำหนดผู้ให้บริการ
- สลับบัญชีเดโมได้เพื่อทดลองยืนยันยอดหลายคน; ไม่ถือเป็น auth หรือการควบคุมสิทธิ์จริง
- ไม่มี Push prompt; in-app notification เพียงพอสำหรับ MVP นี้
