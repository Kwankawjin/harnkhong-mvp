# User flows

## Guest → join

`/` → `/explore` → `/products/:id` → `/groups/:id` → `/groups/:id/join` → `/login` → กลับ `/groups/:id/join` → ยืนยัน → `/groups/:id` → `/my-groups`

การล็อกอินเกิดเฉพาะก่อน action ที่ต้องใช้บัญชี Guest ดูสินค้าและกลุ่มสาธารณะได้

## สร้างและเปลี่ยนกลุ่ม

`/groups/create` ต้องล็อกอิน ตั้งสินค้า ชื่อ จำนวนคน ต้นทุน และ visibility → `/groups/:id` เมื่อสมาชิกเข้า/ออก หรือหัวหน้าปรับค่าส่ง ระบบเพิ่ม revision และล้าง approval ทุกคน สมาชิกยืนยัน revision ปัจจุบัน; order demo เปิดได้เมื่อสมาชิกเต็มและ approval ครบ

หัวหน้ากลุ่มออกไม่ได้จนกว่าโอนสิทธิ์ให้สมาชิกอื่น กลุ่มเฉพาะลิงก์ไม่อยู่ใน public discovery

## ติดต่อผู้ขายและแจ้งเตือน

`/products/:id` → `/chat/:sellerId` โดยล็อกอินก่อน และกลับมาที่แชตเดิม ข้อความตอบกลับสร้างโดย mock ในเบราว์เซอร์ แจ้งเตือนในเว็บสร้างเมื่อสมาชิกเข้า/ออก ยอดเปลี่ยน กลุ่มครบ ยืนยันครบ แชตตอบ หรือคำสั่งซื้อเดโมเปลี่ยนสถานะ กดแจ้งเตือนแล้วอ่านและเปิดหน้าปลายทาง

## Seller demo

ล็อกอินด้วย “ผู้ขายเดโม” → `/seller/dashboard` → `/seller/products/new` → ดูสินค้าที่สร้างใน `/products/:id`
